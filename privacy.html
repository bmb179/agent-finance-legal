Privacy Policy

Last updated: October 12, 2026

This policy describes how Agent Finance Uploader ("the tool") handles information. The tool is operated by Brian Buonauro for his own use only.

What the tool does

The tool uploads videos to a single YouTube channel owned by the operator, Agent Finance, using the YouTube Data API v3 with the youtube.upload scope. It is not offered to the public and does not access any other user's account.

Information we collect

The only information the tool stores is the OAuth access and refresh tokens Google issues when the channel owner authorizes the tool. These tokens are stored securely and used only to upload videos to the operator's own channel. The tool does not collect, store, or process any other personal data, and it does not read viewer data, comments, or analytics.

Sharing

We do not sell, rent, or share any data with third parties. Video files and metadata are sent only to YouTube as part of an upload.

Google and YouTube

The tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

You can revoke the tool's access to your Google account at any time at https://security.google.com/settings/security/permissions. Once access is revoked, stored tokens stop working and are deleted.

Data retention and deletion

Tokens are kept only while access is authorized. To request deletion, revoke access as described above or email the contact below.
